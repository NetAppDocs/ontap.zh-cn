= 使用 ONTAP 系统管理器为 VMware 数据存储库配置 NFS 存储
:hardbreaks:
:toclevels: 1
:allow-uri-read: 
:toclevels: 1
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
在使用 ONTAP tools for VMware vSphere 在基于 ONTAP 的存储系统上为 ESXi 主机配置 NFS 卷之前，请使用适用于 ONTAP 9.7 或更高版本的 System Manager 启用 NFS。

在 System Manager 中创建 link:task_nas_enable_linux_nfs.html["启用了 NFS 的 Storage VM"] 后，使用 ONTAP tools for VMware vSphere 配置 NFS 卷并管理数据存储库。

请务必检查 https://imt.netapp.com/matrix/["NetApp 互操作性表"^]以确认您当前的 ONTAP 和 ONTAP tools for VMware vSphere 版本之间的兼容性。

要使用 System Manager Classic（适用于 ONTAP 9.7 及更早版本）为 ESXi 主机设置对数据存储的 NFS 访问，请参见 https://docs.netapp.com/us-en/ontap-system-manager-classic/nfs-config-esxi/index.html["适用于 ESXi 的 NFS 配置概述"^]

有关详细信息，请参见 https://docs.netapp.com/us-en/netapp-solutions/virtualization/vsphere_ontap_ontap_for_vsphere.html["TR-4597 ：适用于 ONTAP 的 VMware vSphere"^]和 https://docs.netapp.com/us-en/ontap-tools-vmware-vsphere-10/["适用于VMware vSphere的ONTAP工具文档"^]。
