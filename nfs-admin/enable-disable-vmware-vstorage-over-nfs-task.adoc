= 启用或禁用基于 ONTAP NFS 的 VMware vStorage
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以使用  `vserver nfs modify` 命令在 Storage Virtual Machine (SVM) 上启用或禁用对 VMware vStorage over NFS 的支持。此设置控制 VMware VAAI over NFS 操作，如复制卸载和空间保留。

.关于此任务
默认情况下，不支持基于 NFS 的 VMware vStorage 。

从 ONTAP 9.20.1 开始，启用 VMware vStorage over ONTAP NFS 还支持对精简配置的 NFSv3 和 NFSv4.1 数据存储进行自动空间回收。

.步骤
. 验证 SVM 的当前 VMware vStorage over NFS 设置：
+
`vserver nfs show -vserver vserver_name -fields vstorage`

. 执行以下操作之一：
+
[cols="2*"]
|===
| 如果您要 ... | 输入以下命令 ... 


 a| 
启用 VMware vStorage 支持
 a| 
`vserver nfs modify -vserver vserver_name -vstorage enabled`



 a| 
禁用 VMware vStorage 支持
 a| 
`vserver nfs modify -vserver vserver_name -vstorage disabled`

|===
. 验证设置是否已更新：
+
`vserver nfs show -vserver vserver_name -fields vstorage`



.完成后
必须先安装 NetApp NFS Plug-in for VMware VAAI，然后才能使用此功能。自动空间回收需要 3.0 或更高版本。

有关 VMware 主机、插件和互操作性要求，请参阅适用于 VMware VAAI 的 NetApp NFS 插件文档和 NetApp 互操作性矩阵工具。
