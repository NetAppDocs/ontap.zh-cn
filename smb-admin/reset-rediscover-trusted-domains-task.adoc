= 重置并重新发现受信任的ONTAP SMB域
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以强制重新发现所有受信任域。当受信任域服务器未正确响应或信任关系发生更改时，此功能非常有用。只会发现与主域具有双向信任的域，即包含 CIFS 服务器计算机帐户的域。

从 ONTAP 9.13.1 开始，当 ONTAP 重新发现受信任域时，它还会对这些受信任域执行站点发现。ONTAP 将发现的站点信息用于受信任域的域控制器查找。这有助于确保 DNS SRV 查找使用受信任域域控制器的正确站点信息。如果受信任域的站点发现失败，ONTAP 将使用 SMB 服务器的默认站点。

.步骤
. 使用重置和重新发现受信任域 `vserver cifs domain trusts rediscover` 命令：
+
`vserver cifs domain trusts rediscover -vserver vs1`
