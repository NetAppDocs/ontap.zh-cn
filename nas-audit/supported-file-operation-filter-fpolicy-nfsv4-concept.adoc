= ONTAP 中支持的 NFSv4 的 FPolicy 文件操作和筛选器
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
在配置 FPolicy 事件时，您需要注意，在监控 NFSv4 文件访问操作时，仅支持特定的文件操作和筛选器组合。

从ONTAP 9.15.1开始、FPolicy支持NFSv4.1协议。

从 ONTAP 9.19.1 开始，管理员可以在 SVM 级别控制 NFSv4.2 的可用性，使用 System Manager、CLI 或 REST API 为各个存储 VM 启用或禁用该协议。

从 ONTAP 9.20.1 开始，FPolicy 支持监控 NFSv4.2 文件访问事件，包括扩展属性（xattr）写入的新文件操作和标记 NFS 活动的安全标签筛选器。详细了解 link:../nfs-admin/enable-disable-nfs-task.html["为 ONTAP SVM 启用或禁用 NFS"]。


NOTE: 安全标签筛选器(`setattr_with_security_label_change`和 `getattr_with_security_label_read`）要求在 SVM 上启用 NFSv4.2 安全标签（已标记 NFS）。了解有关 link:../nfs-admin/enable-nfsv42-security-labels-task.html["启用 NFSv4.2 安全标签"] 的详细信息。 `getxattr`和 `listxattrs`是只读操作，不受 FPolicy 监控。
