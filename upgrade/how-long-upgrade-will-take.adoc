= ONTAP 升级持续时间指南
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您应计划至少30分钟来完成ONTAP升级的准备步骤、60分钟来升级每个HA对、至少30分钟来完成升级后的步骤。


NOTE: 如果您将 NetApp 加密与外部密钥管理服务器和密钥管理互操作性协议（KMIP）结合使用，您应预计每个 HA 对的升级时间将超过一小时。如果集群使用外部 KMIP 密钥管理器，不在 MetroCluster 配置中，并且 HA 合作伙伴可以提供密钥，则此额外时间不适用于从 ONTAP 9.20.1 开始的自动无中断升级。从 ONTAP 9.20.1 开始，这些集群将从 HA 合作伙伴恢复密钥。请参阅 xref:../encryption-at-rest/configure-external-key-management-overview-concept.html#intracluster-key-sharing[集群内密钥共享]。升级到 ONTAP 9.20.1 仍会从密钥服务器恢复密钥，因此请计划每个 HA 对的升级时间超过一小时。

这些升级持续时间准则基于典型配置和工作负载。您可以使用这些准则来估计在您的环境中执行无中断升级所需的时间。升级过程的实际持续时间取决于您的环境和节点数。
