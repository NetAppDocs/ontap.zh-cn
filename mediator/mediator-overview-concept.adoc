= 了解适用于 MetroCluster IP 和 SnapMirror 主动同步的 ONTAP 调解器
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
ONTAP Mediator 支持 SnapMirror 主动同步和 MetroCluster IP，为高可用性（HA）元数据提供持久且隔离的存储，提供同步节点健康查询功能以帮助确定仲裁，并充当控制器活跃度的 ping 代理。

ONTAP Mediator 在第三故障域中的 Linux 主机上运行，与您的 ONTAP 集群分开，为 HA 元数据提供持久的隔离存储。ONTAP 使用此存储以及 Mediator 的节点健康查询和 ping 代理功能，来监控 SnapMirror 活动同步关系和 MetroCluster IP 配置。

* ONTAP Mediator 使用节点管理 LIF 和集群管理 LIF 通过多个冗余路径与每个集群进行通信。这使得 ONTAP 能够区分整个站点故障和单个 InterSwitch 链路（ISL）故障。
* 在 SnapMirror 活动同步中，如果集群失去与其对等节点和 ONTAP Mediator 的连接，ONTAP 会将该对等节点视为无法访问，并可以自动故障转移到幸存的副本。
* 在 MetroCluster IP 配置中，ONTAP 调解器通过存储有关 MetroCluster 节点的状态信息并帮助确定故障期间的适当操作过程来协助调解器辅助的自动计划外切换（MAUSO）。


要安装或升级本地版本的 ONTAP Mediator，请参见 link:https://docs.netapp.com/us-en/ontap-mediator/index.html["ONTAP Mediator 文档"^]

有关从 ONTAP 9.17.1 开始提供的 ONTAP Cloud Mediator 的信息，请参见 link:../snapmirror-active-sync/index.html["SnapMirror主动同步文档"]。
