= 在 ONTAP 卷迁移期间支持压缩类型共存
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead lead"]
当卷在 ONTAP 系统之间迁移时，源卷可能使用与目标卷不同的数据压缩类型。

支持的压缩类型包括二级、自适应 8K 和温度敏感型存储（TSSE）。在迁移期间，这些压缩类型可以在目标卷上暂时共存，如下所示：

[cols="4"]
|===
| 源卷 | 目标卷 | 支持迁移共存 | 目标卷上的应用程序 I/O 读/写大小 


| 二级压缩类型 | TSSE/32k 内联压缩类型 | 是的。 | 自动 


| 自适应 8k 压缩类型 | TSSE/32k 内联压缩类型 | 是的。 | 自动 


| 二级压缩类型 | 自适应 8k 压缩类型 | 否 | 不支持 
|===
将压缩类型从二级或自适应 8K 压缩更改为 TSSE/32K 内联压缩后，即使所有现有块均已转换， `volume efficiency show` 命令输出中显示的 *compression type* 也不会更改。对于转换后的二级卷，压缩类型仍为 *secondary*，对于转换后的自适应 8K 卷，压缩类型仍为 *adaptive*。

写入从辅助或自适应 8K 压缩转换的卷的新数据使用 TSSE 进行压缩。

学习 link:move-between-secondary-adaptive-compression-task.html["在二级和自适应压缩之间移动"]。
