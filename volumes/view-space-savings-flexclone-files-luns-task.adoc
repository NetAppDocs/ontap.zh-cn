= 通过 FlexClone 文件和 FlexClone LUN 查看 ONTAP 空间节省
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以查看包含FlexClone文件和FlexClone LUN的卷上通过块共享节省的磁盘空间百分比。您可以在容量规划过程中执行此操作。

.步骤
. 查看由于 FlexClone 文件和 FlexClone LUN 而节省的空间：
+
[source, cli]
----
volume show -volume <vol_name> -vserver <SVM> -fields used, sis-space-saved, dedupe-space-saved, compression-space-saved
----
+
[NOTE]
====
如果在启用重复数据删除的 FlexVol 卷上运行此命令，则可以查看重复数据删除以及 FlexClone 文件和 LUN 节省的空间。

====
