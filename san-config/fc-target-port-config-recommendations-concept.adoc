= 确定 ONTAP 系统支持的 FC 目标端口速度
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
FC 目标端口可以按照与 FC 协议完全相同的方式为 FC-NVMe 协议进行配置和使用。

为了获得最佳性能和最高可用性，您应该使用针对特定 ONTAP 系统在 https://hwu.netapp.com["NetApp Hardware Universe"^]中列出的建议目标端口配置。

每个板载 FC 端口和扩展适配器端口可以根据支持的不同速度单独配置。支持的速度因 ONTAP 系统和 HBA 而异。给定主机使用的所有目标端口应设置为相同的速度。

作为最佳做法，您应该在所有启动器、交换机和目标端口上配置通用速度。如果端口和启动器速度不同，并且无法协商通用速度，则无法建立会话。不建议使用自动协商来确定端口速度。自动协商可能会在中断后减慢会话建立和重新连接的速度。

支持的速度列在每个 ONTAP 系统的 NetApp Hardware Universe 的 *Supported Adapter Cards* 下。

.步骤
. 转到 link:https://hwu.netapp.com["NetApp Hardware Universe"^]。
. 选择*产品*。
. 在*平台*下，选择您的系统类型。
. 选择您的特定系统，然后选择您的 ONTAP 版本。
. 选择*显示结果*，然后选择*支持的适配器卡*。
+
FC 适配器卡在*类别*下列为"Block Access (Target)"，支持的速度在*支持的协议*下列出。
