= 更改ONTAP管理员密码
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
首次登录后应立即更改初始 ONTAP 管理员密码，此后应定期更改，以帮助确保群集安全。

从 ONTAP 9.20.1 开始，如果您的用户帐户配置了密码过期警报，System Manager 会在密码过期前 14 天开始显示横幅警报。每次登录时都会更新警报，以显示剩余天数。

.关于此任务
新密码必须遵循以下规则：

* 不能包含用户名
* 长度必须至少为八个字符
* 它必须至少包含一个字母和一个数字
* 不能与最后六个密码相同



NOTE: 您可以使用 `security login role config modify`命令修改与给定角色关联的帐户的密码规则。

.开始之前
* 您必须是集群或 SVM 管理员才能更改自己的密码。
* 您必须是集群管理员才能更改其他管理员的密码。


.步骤
使用 System Manager 或 ONTAP 命令行界面（CLI）更改密码。

[role="tabbed-block"]
====
.System Manager
--
. 在System Manager中、选择*集群>设置*。
. 在*用户和角色*下，选择*用户*。
. 选择需要更改密码的用户帐户旁边的 image:icon_kabob.gif["菜单"]，然后选择 *更改密码*。
. 输入新密码。
. 重新输入新密码进行确认，然后选择 *保存*。


--
.命令行界面
--
如果您是 SVM 管理员，您可以使用  `security login password` 命令更改自己的密码。如果您是集群管理员，您可以使用  `security login password` 命令更改任何管理员的密码。

. 更改管理员密码： `security login password -vserver _svm_name_ -username _user_name_`
+
以下命令更改 SVM `vs1.example.com` 管理员 `admin1`的密码。系统将提示您输入当前密码，然后输入并重新输入新密码。

+
[listing]
----
vs1.example.com::>security login password -vserver engData -username admin1
Please enter your current password:
Please enter a new password:
Please enter it again:
----
