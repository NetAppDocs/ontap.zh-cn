= 在 System Manager 中配置 ONTAP 用户密码过期警报
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
从 ONTAP 9.20.1 开始，如果与用户帐户关联的角色配置了密码过期警报，则用户在登录后会立即在 System Manager 中收到页面顶部横幅警报，该警报从密码过期前 14 天开始显示。每次用户登录时都会更新警报，以显示距离密码过期的剩余天数。您可以在添加或编辑管理员角色时配置过期警报。

.步骤
. 选择*集群>设置*。
. 选择*用户和角色*旁边的 image:icon_arrow.gif["箭头图标"]。
. 添加或编辑用户角色时配置密码过期警报。
+
** 要在添加用户角色时进行配置，请在*角色*下选择image:icon_add.gif["添加图标"]。输入角色的名称，然后选择密码过期时间和密码过期警报。
** 要在编辑用户角色时进行配置，请在*角色*下选择用户角色。选择*编辑*，然后选择密码过期时间。
** 选择 * 添加 * 。




.结果
用户登录后立即在 System Manager 中收到页面顶部横幅警报，从密码过期前的选定天数开始。每次用户登录时都会更新警报，以显示距离密码过期的剩余天数。
