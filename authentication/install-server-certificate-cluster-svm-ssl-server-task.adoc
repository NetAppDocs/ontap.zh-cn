= 在ONTAP中生成并安装CA签名的服务器证书
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
在生产系统上，最佳实践是安装 CA 签名的数字证书，以将集群或 SVM 身份验证为 SSL 服务器。您可以使用 `security certificate generate-csr`命令生成证书签名请求（CSR），并使用 `security certificate install`命令安装从证书颁发机构收到的证书。如需了解有关 `security certificate generate-csr`和 `security certificate install`的更多信息，请参阅 link:https://docs.netapp.com/us-en/ontap-cli/search.html?q=security+certificate["ONTAP 命令参考"^]。



[[generate-a-certificate-signing-request]]
== 生成证书签名请求

您可以使用 `security certificate generate-csr` 用于生成证书签名请求(CSR)的命令。处理请求后，证书颁发机构（ CA ）会向您发送签名数字证书。

.开始之前
要执行此任务，您必须是集群或 SVM 管理员。

.步骤
. 生成 CSR
+
[source, cli]
----
security certificate generate-csr -common-name FQDN_or_common_name -size 512|1024|1536|2048 -country country -state state -locality locality -organization organization -unit unit -email-addr email_of_contact -hash-function SHA1|SHA256|MD5
----
+
以下命令使用由 `SHA256`哈希函数生成的 2048 位私钥创建 CSR。该 CSR 供位于美国加利福尼亚州 Sunnyvale 的公司 `IT`部门中的 `Software`组使用。该公司的自定义公用名为 `server1.companyname.com`。SVM 联系人管理员的电子邮件地址为 `web@example.com`。系统会在输出中显示 CSR 和私钥。

+
.创建CSR的示例
[%collapsible]
====
[listing]
----
cluster1::>security certificate generate-csr -common-name server1.companyname.com -size 2048 -country US -state California -locality Sunnyvale -organization IT -unit Software -email-addr web@example.com -hash-function SHA256

Certificate Signing Request :
-----BEGIN CERTIFICATE REQUEST-----
<certificate_value>
-----END CERTIFICATE REQUEST-----


Private Key :
-----BEGIN RSA PRIVATE KEY-----
<key_value>
-----END RSA PRIVATE KEY-----

NOTE: Keep a copy of your certificate request and private key for future reference.
----
====
. 复制 CSR 输出中的证书请求，并以电子形式（如电子邮件）将其发送到可信的第三方 CA 进行签名。
+

NOTE: 证书颁发机构必须以 base64 编码的 PEM 或 PKCS12 格式返回已签名的证书。

+
处理完您的请求后， CA 会向您发送已签名的数字证书。您应保留一份私钥和 CA 签名数字证书的副本。





[[install-a-ca-signed-server-certificate]]
== 安装 CA 签名的服务器证书

您可以使用 `security certificate install`命令在SVM上安装CA签名的服务器证书。ONTAP 会提示您输入证书颁发机构（ CA ）根证书和中间证书，这些证书构成服务器证书的证书链。有关的详细信息 `security certificate install`，请参见link:https://docs.netapp.com/us-en/ontap-cli/security-certificate-install.html["ONTAP 命令参考"^]。

.开始之前
要执行此任务，您必须是集群或 SVM 管理员。

.步骤
. 安装CA签名的服务器证书：
+
[source, cli]
----
security certificate install -vserver SVM_name -type certificate_type
----
+
[NOTE]
====
ONTAP 提示您输入构成服务器证书的证书链的 CA 根证书和中间证书。该链从颁发服务器证书的 CA 的证书开始，范围可达 CA 的根证书。缺少中间证书会导致服务器证书安装失败。

====
+
以下命令将在SVM上安装CA签名的服务器证书和中间证书 `engData2`。

+
.安装 CA 签名的服务器证书和中间证书的示例
[%collapsible]
====
[listing]
----
cluster1::>security certificate install -vserver engData2 -type server
Please enter Certificate: Press <Enter> when done
-----BEGIN CERTIFICATE-----
<certificate_value>
-----END CERTIFICATE-----


Please enter Private Key: Press <Enter> when done
-----BEGIN RSA PRIVATE KEY-----
<key_value>
-----END RSA PRIVATE KEY-----

Do you want to continue entering root and/or intermediate certificates {y|n}: y

Please enter Intermediate Certificate: Press <Enter> when done
-----BEGIN CERTIFICATE-----
<certificate_value>
-----END CERTIFICATE-----


Do you want to continue entering root and/or intermediate certificates {y|n}: y

Please enter Intermediate Certificate: Press <Enter> when done
-----BEGIN CERTIFICATE-----
<certificate_value>
-----END CERTIFICATE-----


Do you want to continue entering root and/or intermediate certificates {y|n}: n

You should keep a copy of the private key and the CA-signed digital certificate for future reference.
----
====
