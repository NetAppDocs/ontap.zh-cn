= 从 ONTAP System Manager 仪表板查看集群信息
:hardbreaks:
:toclevels: 1
:allow-uri-read: 
:toclevels: 1
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
System Manager信息板可从一个位置快速全面地查看您的ONTAP集群。

从 System Manager 仪表板，您可以查看有关群集运行状况、容量、网络和性能的信息，包括重要警报、存储层和卷的效率和容量、群集节点的状态和可用性、最活跃的应用程序和对象以及性能指标。

从 ONTAP 9.19.1 开始，SVM 管理员可以使用 ONTAP System Manager 中的专用 SVM 管理员仪表板来监控和管理自己的 SVM。有关详细信息，请参见link:task-svm-admin-dashboard-sm.html["使用 System Manager 管理和监控 SVM"]。

信息板包括四个面板、如下所述：



[[view-the-cluster-health]]
== 查看集群运行状况

在 ONTAP System Manager 仪表板的 *Health* 部分，您可以查看有关集群的一般信息，例如其名称、ONTAP 版本和创建日期。您还可以查看集群节点的整体运行状况、集群级错误、警告、警报以及旨在提高集群性能的建议修改。

从 ONTAP 9.20.1 开始，在集群或存储虚拟机（SVM）证书过期前 30 天会显示运行状况警报。该警报每天都会更新，以显示距离过期的剩余天数。您可以将默认的 30 天警报阈值修改为 0 到 90 之间的任何天数，将其禁用以不显示任何警报，或者禁止显示已过期证书的警报，同时继续接收即将过期的警报。

* 要查看集群健康信息，请选择仪表板上 *健康* 旁边的 image:icon_arrow.gif["箭头图标"]。
* 要修改证书到期设置，请选择警报，然后选择*证书设置*。




[[view-the-cluster-capacity]]
== 查看集群容量

在 ONTAP System Manager 仪表板的*容量*部分中，您可以查看集群的存储空间。您可以查看已使用的总逻辑空间、已使用的总物理空间和可用磁盘空间。

您可以选择向 ActiveIQ 注册以查看历史集群数据。

选择仪表板上 *容量* 旁边的 image:icon_arrow.gif["箭头图标"]，查看集群容量信息，包括与集群关联的层的概述，例如总空间、已用空间和可用空间。此外，还会显示吞吐量、IOPS 和延迟的详细信息。link:./concepts/capacity-measurements.html["了解 ONTAP 如何报告已用存储"]。

您可以使用容量视图选择添加本地层或云层。有关详细信息，请参阅 link:task_admin_monitor_capacity_in_sm.html["查看集群的容量"]。



[[view-the-cluster-network]]
== 查看集群网络

在 ONTAP System Manager 仪表板的 *网络* 部分，您可以查看网络中的物理端口、网络接口和存储 VM。

网络视图显示连接到网络的客户端的类型。其中每个网络连接客户端均由一个数字表示(例如、"NVMe/FC 16")。选择该数字可查看有关每个网络元素的特定详细信息。

选择仪表板上 *网络* 旁边的 image:icon_arrow.gif["箭头图标"] ，以查看包含网络上的端口、网络接口、存储虚拟机和主机的网络扩展全页视图。



[[view-the-cluster-performance]]
== 查看集群性能

在 ONTAP System Manager 仪表板的 *性能* 部分，您可以查看性能统计信息，以帮助监控 ONTAP 集群的运行状况和效率。这些统计数据包括以图形表示的关键集群性能指标，如延迟、吞吐量和 IOPS。

性能视图按天、小时、周或年显示不同时间间隔的性能统计信息。您可以使用各种图形快速分析集群性能、并确定可能需要优化的特征。此快速分析可帮助您确定如何添加或移动工作负载。您还可以查看峰值使用时间以规划潜在的更改。

性能视图显示与延迟、吞吐量和IOPS相关的总性能指标。

从9.15.1开始、性能视图得到了增强、可显示与延迟、吞吐量和IOPS相关的读取、写入、其他和总性能指标的图形。其他指标包括任何不读取或写入的操作。

性能值每 3 秒刷新一次，性能图每 15 秒刷新一次。如果有关集群性能的信息不可用、则不会显示图形。

选择控制面板上 *性能* 旁边的 image:icon-expansion-arrows.png["扩展图标"]，即可按小时、天、周、月和年查看性能指标的全页视图。您还可以将性能指标报告下载到本地系统。
